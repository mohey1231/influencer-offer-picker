# منسّق عروض المؤثرين

صفحة واحدة بتختار منها مؤثرين من شيت Excel، والإجمالي بيتحسب لوحده مقابل ميزانية العميل، وبعدين تطلع العرض PDF متنسق.

## بتعمل إيه
- تسجيل دخول بالإيميل (Supabase). الأدمن بيضيف ويشيل الإيميلات من زرار «المستخدمون».
- قائمة المؤثرين: اسم المؤثر، حساباته (سناب / تيك توك / انستجرام… الشخص ممكن يبقى له أكتر من حساب)، الفئة A / B / C، المنطقة، والسعر.
- استيراد شيت المؤثرين (xlsx / xls / csv). الصفحة بتلاقي الأعمدة لوحدها، والاسم المتكرر بيتدمج في مؤثر واحد بكل حساباته.
- بحث، وفلتر بالمنصة والفئة والمنطقة ورينج السعر، وترتيب.
- مسودة حملة فيها إجمالي لكل منصة، وشريط للميزانية والمتبقي منها.
- بروفايل خفيف لكل مؤثر.
- تصدير PDF: نسخة للعميل فيها سعر البيع بس، ونسخة داخلية فيها التكلفة والربح.

## ملاحظات
- البيانات اللي في الصفحة وهمية للعرض بس، والفئات متوزعة عشوائي لحد ما الشيت الحقيقي يوصل.
- إعداد قاعدة البيانات كله في `supabase-setup.sql`.
- الشيت اللي بترفعه بيتحفظ على المتصفح بتاعك بس، ومش بيترفع على أي سيرفر.
- حفظ الحملات ومشاركتها مع الفريق مش موجود في النسخة دي، ومحتاج قاعدة بيانات (زي Supabase).

## التشغيل
افتح `index.html` في أي متصفح، أو استخدم رابط GitHub Pages.
