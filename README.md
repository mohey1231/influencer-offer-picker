# منسّق عروض المؤثرين

صفحة واحدة بتختار منها مؤثرين من شيت Excel، والإجمالي بيتحسب لوحده مقابل ميزانية العميل، وبعدين تطلع العرض PDF متنسق.

## بتعمل إيه
- تسجيل دخول باسم مستخدم وكلمة مرور (Supabase). المسؤول بيعمل المستخدمين من جوه من زرار «المستخدمون»: اسم مستخدم + كلمة مرور + صلاحية، وبيقدر يغيّر كلمة المرور أو يحذف المستخدم. أول مرة بس، الصفحة بتطلب كلمة مرور لحساب admin.
- قائمة المؤثرين بنفس أعمدة شيت الفريق: اسم المؤثر، الفئة A / B / C، السعر الرسمي وسعر أوت مارك للإعلان المنزلي والتغطية، المنصة، طريقة الوصول، رقم التواصل، رابط الحساب، والملاحظات. المنطقة من اسم الورقة أو من عناوين «منطقة …».
- استيراد من ملف (xlsx / xls / csv) أو من لينك Google Sheets (لازم يكون متشارك «أي شخص لديه الرابط»). فيه اختيار «إضافة» أو «استبدال»، ومعاينة قبل الحفظ بالجداد واللي هيتحدّثوا واللي هيتشالوا.
- «تعديل البيانات» من بروفايل المؤثر لأي حاجة ناقصة (رابط، رقم، أسعار، ملاحظات…)، وزرار «إضافة مؤثر» لمؤثر جديد.
- حذف: مؤثر واحد من البروفايل، أو «تحديد للحذف» لأكتر من واحد، أو «حذف كل المؤثرين»، وكل حذف فيه تأكيد و«تراجع».
- في الحملة كل مؤثر ليه نوع إعلان (منزلي / تغطية) وتقدر تبدّل بينهم، والسعر بيتغير لوحده.
- بحث، وفلتر بالمنصة والفئة والمنطقة ورينج السعر، وترتيب.
- مسودة حملة فيها إجمالي لكل منصة، وشريط للميزانية والمتبقي منها.
- بروفايل خفيف لكل مؤثر.
- تصدير PDF: نسخة للعميل فيها سعر البيع بس، ونسخة داخلية فيها التكلفة والربح.

## ملاحظات
- البيانات التجريبية اللي في الصفحة وهمية، وبتظهر بس لحد ما شيت الفريق يتستورد.
- إعداد قاعدة البيانات كله في `supabase-setup.sql`.
- الحملات والشيت ونسبة الهامش بيتحفظوا في قاعدة بيانات الفريق على Supabase (جدول `docs`، الإعداد في `supabase-data.sql`)، وأي تعديل بيظهر لكل الفريق على طول. الحملات القديمة اللي كانت على المتصفح بتتنقل للقاعدة لوحدها أول مرة تدخل.

## التشغيل
افتح `index.html` في أي متصفح، أو استخدم رابط GitHub Pages.
